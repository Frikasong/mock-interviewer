# Mock Interviewer

A single HTML file. Open it in Chrome, answer one question at a time against a real clock, and leave with a debrief file your AI coach can mark up.

No install, no build step, no account, no API key. Nothing leaves your machine — there is no server to send it to.

一个 HTML 文件。用 Chrome 打开，一次一题、对着真实计时作答，结束后拿到一份可以直接交给 AI 教练批改的复盘文件。

不用安装、不用构建、不用注册、不需要 API key。数据不离开你的电脑——因为根本没有服务器可以发过去。

---

## Quick start / 快速开始

1. Download `index.html` (that's the whole tool).
2. Double-click it, or drag it into Chrome.
3. Allow camera and microphone when asked. Both are optional — the tool works with either turned off.
4. Pick a starting script, or paste your own question bank.
5. Paste your prepared material into "What you prepared". **This is the step people skip and it's the one that makes the debrief worth reading** — knowing what you prepared is the only way anything can tell you what you dropped under pressure.
6. Answer. Space bar starts and stops.
7. Download the debrief and hand it to Claude, ChatGPT, or whatever you use, with the prompt already written at the top of the file.

中文：下载 `index.html` → 用 Chrome 打开 → 允许摄像头和麦克风（都可以关，关了也能用）→ 选脚本或粘贴自己的题库 → **把准备好的材料粘进「你准备了什么」那一栏**（这一步最容易被跳过，但复盘有没有用全看它）→ 开始作答，空格键开始/结束 → 下载复盘，连同文件顶部已经写好的 prompt 一起丢给 AI。

## What it does

- **One question at a time.** The question appears on a card, read aloud if you want it read. You answer, you stop, you get the next one. Firing off a whole list and grading in bulk is an exam, not an interview.
- **A real clock.** Each question carries a time budget. The line under the card fills as it burns — teal, then amber past three quarters, then red when you're over. For the first fifteen seconds a line above the card reminds you to lead with your answer, because that's where most answers are lost.
- **Video and transcript.** Your webcam records each answer as a separate clip. Live speech-to-text fills in the transcript, which you can correct afterwards — recognisers mishear proper nouns constantly.
- **Reading exercises.** A question tagged `type: case` gets a timed reading phase before the timed answer, and its answer key stays hidden until the debrief.
- **A debrief that knows what you prepared.** The exported markdown puts your prepared opener and intended story next to what you actually said, question by question, with times against budgets. That comparison is the whole point.

## What it deliberately doesn't do

- **No AI inside the tool.** No key to paste, no cost, no vendor lock-in, and no recording of yours ever passing through someone else's inference. The debrief is designed to be pasted into whatever assistant you already pay for.
- **No cloud storage.** Close the tab and the recordings are gone unless you downloaded them. That is the intended behaviour for a file full of your own unpolished interview answers.
- **No scoring model.** A number generated by a stopwatch and three checkboxes isn't an assessment. The tool measures what can be measured — time, words, whether you ticked the box — and leaves judgment to a reader who can actually judge.

## Question bank format

Plain markdown. `###` per question, fields below it:

```markdown
### Tell me about a time you disagreed with a supervisor.
- type: behavioural
- budget: 120s
- best story: S03
- backup: S07
- opener: I raised it early, in writing, and framed it as a risk to the file.
- watch: no more than two sentences of background
```

Field names work in English or Chinese (`最优素材`, `开场句`, `注意` and so on). `budget` accepts `90`, `90s`, or `2m`. Everything is optional except the question itself.

For a reading exercise, indent the continuation lines:

```markdown
### Fact pattern: advise the client.
- type: case
- reading: 15m
- budget: 15m
- fact:
  A regulated entity has filed late for three consecutive quarters…
  The regulator's enforcement staff have asked for a meeting.
- key:
  Strong answers lead with the recommendation before the reasoning…
```

This is the format the [`interview-prep`](../skills) skill produces, so a bank built there loads without editing. The `scripts/` folder holds five ready-made banks you can edit instead of starting blank.

## Browser support

| | Chrome / Edge | Safari | Firefox |
|---|---|---|---|
| Questions, timers, debrief export | ✅ | ✅ | ✅ |
| Video recording | ✅ | ✅ | ✅ |
| Live transcript | ✅ | — | — |
| Questions read aloud | ✅ | ✅ | ✅ |

Live transcription uses the browser's built-in speech recognition, which only Chrome and Edge implement today. Without it, everything else still works and you type or leave the transcript blank — though the debrief gets much weaker, since your coach has nothing to read.

## Keyboard

`Space` — start answering / stop answering / next question.
