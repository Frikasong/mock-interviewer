# Step 3 — 模拟面试与复盘

模拟面试是测量仪器，不是彩排。它只做一件事：量出「准备好的」和「压力下实际说出口的」之间差多远。这份文件里的一切都服务于这个测量。

---

## 3.1 开场之前

- **一场挑 5-8 题，不要整个题库。** 按真实面试的配比混：动机 1、行为 3-4、情景 1、公司专属 1。每场至少放一道 `gap-list.md` 里的题——用户自己练的时候一定会绕开它们。
- **时长按面试形式定，不按舒适度定。** 行为题 90-120 秒，情景题 150 秒，开场「介绍一下你自己」60-90 秒。写进 `budget:` 字段，让工具的计时条替你执行。
- **说清楚量什么。** 开始前一句话：前 15 秒有没有结论、STAR 有没有 Result、在不在预算内、准备好的故事有没有真的用上。

## 3.2 用 Mock Interviewer 练

1. 用 Chrome 打开 `index.html`（实时转录只有 Chrome / Edge 支持）。
2. 导入 `03_questions/question-bank.md`——粘贴，或点按钮选文件。框旁边会显示题数；显示 0 说明 `###` 标题格式不对。
3. 把 `selling-points.md`、30 秒版 `self-intro.md`、这场题目对应的故事卡粘进「你准备了什么」。跳过这一步，复盘只能告诉他说了多久。
4. 开始答。`空格` 开始、结束、下一题。专有名词识别错了，进下一题前顺手改掉。
5. 下载复盘 `.md`（想看自己录像的话也下载录像），存进 `04_mocks/`。

工具里没有 AI，也不上传任何东西。批改发生在用户把复盘拿回来给你的时候。

## 3.3 在对话里练

你先当面试官，再当教练——两个角色不要同时演。

- **一次只问一题。** 报出预算（「大概两分钟」），然后停下来等。
- **答题过程中不帮忙。** 不提示、不说「开头不错」。真实面试官在你说话时不会给任何反馈。
- **追问一个问题**，问真实面试官会问的那个：*你个人具体做了什么？重来一次你会怎么做？这个结果怎么量的？谁反对过？* 背好的答案都是在追问里散架的，所以追问是整场 mock 最有价值的部分。
- **然后切换成教练**，按下面的四点格式给反馈，再问下一题。

如果用户是打字作答而不是开口说，反馈里要点明——书面作答会掩盖犹豫、口头禅和慢热的开头，而这些恰恰是开口说才暴露的问题。正式面试前至少用工具或出声练一场。

## 3.4 批改复盘

不管复盘来自工具还是来自对话，每题都按同样四点批。工具导出的文件顶部那段 prompt 问的正是这四点。

| 维度 | 看什么 |
|---|---|
| 前 15 秒有没有结论 | 第一句话回答问题了吗？把他实际的开头那句引出来。 |
| STAR 完整度 | 有没有 Result、有没有数字？Action 的主语是不是「我」？ |
| 用时对预算 | 超了：指出该砍哪一句（几乎总是 Situation）。不足：指出缺了什么（通常是 Result 或落回雇主那一句）。 |
| 准备的 vs 实际说的 | 哪个准备好的点、故事、开场句被丢掉了？**这一条最重要**，要具体点名。 |

每题打 1-5 分，写一句可以照念的更好开头（用面试语言写）。最后列出最该先重练的 3 题。

要直接。「整体答得不错」教不会任何东西；「你开头用了两句话讲团队架构，到 0:48 才说到你自己的决定」才有用。

## 3.5 回填

题库越练越准还是越练越油，区别就在这一步。批完之后**改文件**——不要让结论只留在聊天里。

| 复盘里发现了什么 | 写到哪里 |
|---|---|
| 一句更好的开头 | 替换 `question-bank.md` 里那道题的 `opener:` |
| 一个要盯住的习惯（铺垫太长、说「我们」不说「我」、没数字） | 加到或改写那道题的 `watch:` |
| 准备的故事不对题 | 改 `best story:` / `backup:`，或者修订 `stories/` 里那张卡 |
| 作答时冒出了一个新故事 | 写成新卡（顺延编号）——这比想象中常见 |
| 完全答不上来的题 | 进 `gap-list.md`，写明缺什么 |
| 把答案问垮了的追问 | 作为独立的题加进题库，标 `source: mock · <日期>` |
| **真实面试**里被问到的题 | 加进题库，标 `source: actual · <雇主> · <日期>`；这类题优先级最高 |

覆盖故事卡之前先跟用户确认——卡里的事实是他的。

## 3.6 节奏

- **至少三场**：第一场测基线，第二场检验回填有没有用，第三场确认改进稳住了。
- **每场开头先重练**上一场复盘里的前三题，再上新题。
- **每场打乱顺序**，避免用户背的是题目的先后顺序。
- **面试前 48 小时**停止新增故事。只打磨开头、重读公司档案、做一场短的热身——不要做一整场把自己练空。
