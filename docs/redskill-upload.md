# RED Skill 上传表单 · 照抄

PC 端登录小红书创作者服务平台 → 左侧菜单 **Red Skill** → 上传。
（手机端也可以：发笔记时点「组件」→ Red Skill。）

**上传方式选「文件夹上传」**，把 `dist/redskill/interview-prep-zh/` 整个拖进去。
如果只接受单个文件，或者你走的是「对话上传」被拍平了结构，改用 `interview-prep-zh-single.md`——那一份把 references 和模板全内联了，功能不打折。

## Skill 名称

```
面试准备·三步法
```

不要叫 interview-prep。中文名在信息流里才被读得到，而且这个名字自己说清了它是什么。

## 简介

```
面试转化率取决于匹配度：认识雇主，也认识你自己。

这个 skill 不直接给你答案，它帮你建两份资料——
第一步，拆 job description、建公司档案、写站得住的 Why Them；
第二步，逐行逼问你的简历，把经历拆成编号的 STAR 故事卡。

有了这两份资料，AI 才说得出「这题你准备了 S07，临场用了更弱的例子」
这种话；没有它们，你得到的永远是对任何人都成立的万能答案。

作者六个面试拿到三个 offer 时用的就是这套方法。
```

## 场景标签

```
求职  面试  简历  职场  效率
```

平台已有「面试助手」这个品类，能对上就对上。

## 上传后自己验一遍

审核通过不等于装上能跑。用另一个设备或另一个账号走一遍完整链路：

1. 点笔记里的组件 → 复制口令
2. 粘到 Claude Code（或 OpenClaw）
3. 装完之后，**不要**说「帮我用面试准备 skill」——那是作弊。
   说一句真实用户会说的话：「我下周四面 XX 公司的 XX 岗，这是 job posting」
4. 看它自己触发没有

触发不了就回来改 frontmatter 的 description——触发词不够覆盖口语说法是最常见的原因。改完重新上传即可，不用改正文。

## 挂载笔记时

组件挂在**演示视频那条笔记**下面，不要单独发一条「我发了个 skill」的笔记。

RED Skill 的逻辑是内容即分发：用户先被内容说服，再顺手装。一条没有内容、只有组件的笔记，转化会很差，也拿不到流量扶持。

视频最后那句「skill 和工具放评论区了」可以改成「skill 挂在下面了」——组件比评论区链接的转化高一个量级。
